# README Localization

## Policy

`README.md` is the canonical United States English document. `README.ja.md` is a Japanese translation target and should stay aligned with the same section order, command examples, safety boundaries, and verification steps.

## Update Flow

When `README.md` changes, update `README.ja.md` in the same change or record the translation gap before publishing. Language-specific wording can differ naturally, but setup commands, paths, scope boundaries, and warnings must not diverge.
